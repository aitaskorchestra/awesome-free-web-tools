## Screenshots & Visual Testing

| Tool | Description | Free Tier |
|------|-------------|-----------|
| [GrabShot](https://grabshot.dev) | Screenshot API with device frames and AI cleanup | 25 screenshots/mo |
| [Puppeteer](https://pptr.dev) | Headless Chrome automation by Google | Open source |
| [Playwright](https://playwright.dev) | Cross-browser automation by Microsoft | Open source |
| [Screenshot.rocks](https://screenshot.rocks) | Browser mockup generator | Free |
| [Urlbox](https://urlbox.io) | Automated website screenshots | 100/mo free |

## PDF Generation
